# Length of String

![Difficulty](https://img.shields.io/badge/Difficulty-Basic-red)

## Problem

Given a string  **s**, return the  **length**  of the string.

 **Examples:** 

```
Input: s = "Geeks"
Output: 5
```

```
Input: s = "Hello1234"
Output: 9
```

 **Constraints:** 
1 ≤ |s| ≤ 105

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-10-04T11:49:20.164Z  

```java
class Solution {
    public static int lengthString(String s) {
        // code here
        return s.length();
    }
}
```
